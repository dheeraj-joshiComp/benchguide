# BenchChat Study Guide

Participant instructions site for the BenchChat study. React + Vite, no backend.

- Edit copy and links in `src/content.js`.
- `npm install` then `npm run dev` to run locally.
- `npm run build` outputs static files to `dist/`.

## Deploy on Vercel
Import this repo in Vercel (Add New → Project). Vercel detects Vite automatically:
build command `npm run build`, output directory `dist`.
